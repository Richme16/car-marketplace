# Motorline — Car Sales & Rental Marketplace

A web app for browsing, buying, and renting cars. Built as a learning project, step by step.

## Status

🚧 In progress — frontend listings page complete. Backend and database coming next.

## Features (so far)

- Browse car listings in a responsive grid
- Search by make/model
- Filter by listing type (for sale / for rent)
- Sort by price or mileage

## Planned

- [ ] Backend API (Node.js + Express)
- [ ] Database (MongoDB) for real car listings
- [ ] Booking/purchase forms that actually submit
- [ ] User accounts (sign in / sign up)
- [ ] Admin panel to add/edit/remove listings
- [ ] Deployment (frontend on Vercel/Netlify, backend on Render)

## Tech stack

- **Frontend:** HTML, CSS, JavaScript (vanilla for now)
- **Backend (planned):** Node.js, Express
- **Database (planned):** MongoDB

## Running locally

1. Clone this repo
2. Open `frontend/index.html` in a browser, or use the VS Code "Live Server" extension for auto-reload during development
